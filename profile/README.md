# Dev Machine

devmachine sets up a VPS for you to code on. Each project gets its own
account on the server, called a workspace, with its own tools, logins and
coding agent.

```
brew install mydevmachine/tap/devmachine
devmachine setup
```

**Documentation: https://mydevmachine.sh/**

## Repositories

| Repository | What it is |
| --- | --- |
| [devmachine](https://github.com/mydevmachine/devmachine) | The CLI (Go) |
| [packages](https://github.com/mydevmachine/packages) | Ready-made packages to add to a workspace |
| [docs](https://github.com/mydevmachine/docs) | Source of the documentation site |
| [homebrew-tap](https://github.com/mydevmachine/homebrew-tap) | Homebrew tap: `brew install mydevmachine/tap/devmachine` |
| [app-releases](https://github.com/mydevmachine/app-releases) | Signed and notarized builds of the Mac app |
